Python Decorators
-----------------
-  add extra behavior to a function, without changing the function's code.
- Decorators is a function that takes another fn as input and return a new function

Arguments in the Decorated Function
-----------------------------------
Functions that require arguments can also be decorated, just make sure you pass the arguments to the wrapper function

Python Lambda
-------------
- small anonymous function.
- can take any number of arguments, but can only have one expression
    SYNTAX
    -----
    lambda arguments : expression 
 -expression is executed and the result is returned


Why Use Lambda Functions?
The power of lambda is better shown when you use them as an anonymous function inside another function.

Say you have a function definition that takes one argument, and that argument will be multiplied with an unknown number

Lambda with Built-in Functions
------------------------------
Lambda functions are commonly used with built-in functions like map(), filter(), and sorted()

map()
-----
applies a function to every item in an iterable

filter()
--------
creates a list of items for which a function returns True

sorted()
--------
use a lambda as a key for custom sorting

PYTHON RECURSION
----------------
- function calling itself
- recursive function must have two parts
    A base case - A condition that stops the recursion
    A recursive case - The function calling itself with a modified argument

- Without a base case, the function would call itself forever, causing a stack overflow error

    def factorial(n):
    # Base case
    if n == 0 or n == 1:
        return 1
    # Recursive case
    else:
        return n * factorial(n - 1)

print(factorial(5))

- Recursion with Lists
Recursion can be used to process lists by handling one element at a time

Python has a recursion limit of 1000- can change the limit by importing sys , sys,recursionlimit(2000)

Generators
----------
- is a function which ca pause and resume their execution
-if called this function, it returns a Generator object, which is an iterator.

- Generator iterate over the data without storing the entire dataset
- here instead of return we use yield keyword, this keywordmakes a function Generator
- when yield is calles the function state is saved and it returns the value. if called again, it continues from where it left.

- return keyword will terminates the function while the yield keyword pauses and can be called multiple times.

- Generators are memory-efficient, coz they dontstores everything in memory
- large datasets, generators save memory

- manually iterate through a generator using the next() function

- create generators using generator expressions with parentheses instead of square brackets

Generator Methods
-----------------
send() -  send a value to the generator
close() - stops the generator


PYTHON RANGE
------------
range() - returns an immutable sequence of numbers, commonly used for looping a specific number of times

    range(start, stop, step)

 - one argument, the argument represents the stop value
 - start argument is optional, if not defaults to 0

- range(10) returns 0 to 9 
- range(3, 10) returns a sequence of each number from 3 to 9
- range(3, 10, 2) returns a sequence of each number from 3 to 9, with a step of 2

- ranges() used often in for loops to iterate over a sequence of numbers

- ranges can be sliced to extract a subsequence

- Ranges support membership testing with the in operator. return value is True when the number is present in the range, and False when it is not.
